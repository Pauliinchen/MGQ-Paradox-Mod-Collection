# TimeStop Music

Keeps the battle music playing through time stop. Without it, the game fades the music to silence while time is stopped.

The time stop screen effect stays as it is.

## Install

1. Install the community's mod loader: the `Patch.rb` from [*Patch.rb (enable Type 1 mods)*](https://mgq.miraheze.org/wiki/Paradox_mods#Patch.rb_(enable_Type_1_mods)) on the MGQ wiki, in your `Patch` folder. If you already use other Patch folder mods, you have it.
2. [Download `TimeStop_Music.rb`](https://github.com/Pauliinchen/MGQ-Paradox-Mod-Collection/raw/main/TimeStop_Music/TimeStop_Music.rb) and put it into the `Patch` folder.

To uninstall, delete `Patch\TimeStop_Music.rb`.

## Compatibility

Tested on 3.06 with the English translation.
